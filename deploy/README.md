# Deployment

Сервис разворачивается на SSH host `uptick`:

- бинарник и конфигурация: `/opt/hackersprint2-sim`;
- постоянные SQLite/journal данные: `/var/lib/hackersprint2-sim`;
- systemd unit: `hackersprint2-sim.service`;
- HTTP address: `0.0.0.0:8080`;
- процесс работает от системного пользователя `hackersprint2-sim`.

Первичная установка без автоматического запуска:

```bash
make install
make start
```

Обновление уже установленного сервиса:

Переход на `world-generator.v12` / `world-generation.v2.yaml` требует пустого
хранилища: старые каталог и журналы торгового симулятора несовместимы с новым
форматом. До первого запуска новой версии остановите сервис и отдельно
подготовьте пустой data directory. `sync` не удаляет серверные данные и не
выполняет их миграцию. Очистка локального `data/` не очищает сервер деплоя.

```bash
make sync
make restart
```

Компактные сводки для списков `/ui` и `/debug` хранятся в `catalog.db` и
обновляются при записи журнала. Таблица добавляется автоматически без очистки
данных. При первом чтении старого run его сводка строится из журнала; последующие
чтения, в том числе после рестарта, используют сохранённую сводку. Если запись
сводки была прервана, несовпадение ревизии журнала вызывает её перестроение.

Управление и логи:

```bash
make stop
make start
make restart
make logs
make logs LOG_LINES=500
```

Все команды принимают другой SSH host через `DEPLOY_HOST`, например
`make sync DEPLOY_HOST=root@example.org`. `sync` атомарно заменяет бинарник,
конфигурацию и копию unit-файла, но не перезапускает работающий процесс.
