# HTTP agent

Минимальный внешний агент для симулятора. Он знает только публичный HTTP API и
не импортирует внутренние пакеты проекта.

На каждом шаге агент:

1. читает новые ошибки из логов и применяет найденные fix keys;
2. запускает первый доступный deployment;
3. добавляет сервер после `SERVER_CAPACITY_EXCEEDED` либо удаляет один
   простаивающий сервер;
4. перематывает симуляцию на сутки.

Запуск против развернутого симулятора:

```bash
make run-http-agent SEED=1
```

Другой адрес симулятора можно передать через Make:

```bash
make run-http-agent SEED=1 SIMULATOR_URL=http://127.0.0.1:8080
```

Либо запустить проект напрямую:

```bash
go run ./cmd/httpagent -url http://127.0.0.1:8080 -seed 1
```
