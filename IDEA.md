# Мир симуляции

Мы моделируем IT-компанию, которая разрабатывает и эксплуатирует интернет-магазин.

Интернет-магазин работает в облачной инфраструктуре и состоит из нескольких типичных компонентов: frontend, backend-сервисы, база данных, cache, очереди, фоновые workers и интеграции с внешними системами, например платежным провайдером.

Компания постоянно развивает продукт: происходят deploy новых версий, изменения конфигурации и миграции базы данных. Одновременно реальными пользователями создается нагрузка на работающую production-систему.

Во время эксплуатации происходят обычные для production события: рост нагрузки, сбои сервисов, проблемы с базой данных, нехватка ресурсов, ошибки после deploy, проблемы внешних провайдеров, DDoS/brute-force атаки, утечки credentials и другие инциденты.

Эти события изменяют состояние мира и отражаются в наблюдаемых показателях: availability, latency, error rate, нагрузке на инфраструктуру, количестве успешных заказов, потерянной выручке и т. д.
